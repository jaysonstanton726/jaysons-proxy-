# Jaysons Proxy

A simple, responsive personal web portal (not a proxy service).

## Publish with GitHub Pages

1. Sign in to GitHub and create a new **public** repository named `jaysons-proxy`.
2. Upload `index.html` to the repository's top level (the root).
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Choose branch `main` and folder `/ (root)`, then save.
6. Wait a minute or two. GitHub will show your Pages URL in the Pages settings.

This project is a start page with ordinary search and shortcut links. It does not bypass school filters or network restrictions.
